# SSL

This service lets you add domains to a watchlist and track their SSL certificate expiry status.

## 1. Add Domain to Watchlist
  
- Add a domain to the watchlist by entering the domain name (including port, if applicable).
- The service checks if the domain has a valid A record and displays its SSL expiry date.
- Once added, you can track the domain's expiry and renew before it expires.

## 2. Domain Status
   
- View all domains in the watchlist or search for specific domains.
- Displays the SSL expiry date of added domains.
